# Foyers fictifs de référence

Un fichier JSON par foyer, au format d'entrée de l'API OpenFisca (`/calculate`). Les montants attendus sont relevés à la main sur les simulateurs officiels (CAF, mesdroitssociaux.gouv.fr), avec la date du relevé.

| Fichier | Situation | Statut |
| --- | --- | --- |
| `01-smic-seul.json` | Salarié seul au SMIC, locataire | à écrire |
| `02-couple-2-enfants.json` | Couple, deux enfants, un seul revenu | à écrire |
| `03-parent-isole.json` | Parent isolé, un enfant, temps partiel | à écrire |
| `04-etudiant.json` | Étudiant boursier, locataire | à écrire |
| `05-retraite.json` | Retraité seul, petite pension | à écrire |

Toutes les données sont **fictives**. Jamais de vraie situation dans ce dossier.
